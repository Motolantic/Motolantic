# Panduan Arsip Darurat

## Menyimpan dokumen

1. Pastikan dokumen layak dibagikan di repo publik dan tidak memuat kredensial atau data operasional.
2. Gunakan nama deskriptif dengan tanggal YYYY-MM-DD.
3. Simpan checkpoint di archives/checkpoints/; buat folder tematik jika diperlukan.
4. Perbarui archives/README.md.
5. Gunakan pesan commit yang menjelaskan perubahan.

## Keputusan baru

Pertahankan checkpoint lama. Buat checkpoint baru untuk keputusan berikutnya dan jelaskan perubahan. Koreksi faktual pada dokumen lama harus disertai catatan koreksi.

## Pemulihan

- Buka Code → Download ZIP di GitHub untuk mengunduh dokumen saat ini.
- Untuk membawa riwayat revisi, gunakan `git clone https://github.com/amangkaban56-sketch/Motolantic.git`.
- Baca README, indeks arsip, lalu checkpoint yang diperlukan.
- Gunakan riwayat commit untuk menelusuri versi terdahulu.

Repo ini hanya memulihkan materi yang telah diunggah. Repo ini tidak memulihkan database, layanan produksi, ataupun dokumen yang belum disimpan.
